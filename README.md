# Lead Status Flow

Static page: where every contact created in 2026 lands on HubSpot lead status today, and where it would
land under the proposed route-based rules, plus how contacts move after that.

Live: https://eldeebbomar.github.io/vespa-lead-status-flow/ (not indexed by search engines).

Generated, never hand-edited. The page reads every number from an embedded JSON produced by the
project's `lead_status_flow_numbers.py`, and `lead_status_flow_page.py --pages <dir>` writes this
`index.html`.
